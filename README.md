# 时序预测与表征诊断

独立项目位于 [`forecast_lab/`](forecast_lab/README.md)：先直接监督预测，再监测表征、进行编码干预，最后按证据选择辅助正则。

- 神经网络编码器 + 预测头，默认不做自适应压缩或重构预训练。
- 按时间划分数据，支持 `date + 数值列` 格式的多变量 CSV。
- 自动生成离线交互报告、PNG 图片、逐轮监测记录和服务器运行日志。
- 支持冻结检查点评估，以及多个种子、预测长度和正则设置的对照。
- 第二轮代码支持残差预测、近端加权、编码宽度对照、范围审计和重复探针抽样，见 [服务器实验说明](forecast_lab/EXPERIMENTS_V2.md)。

本次交付按要求没有在本机运行训练、测试或生成实验结果。安装与验证请在目标服务器执行，见项目说明。
